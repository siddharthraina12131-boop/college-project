# College Project — FitAI

FitAI is an Android college project built with Kotlin, Jetpack Compose, and an offline Decision Tree machine-learning classifier.

## Open the project

1. Download [FitAI.zip](FitAI.zip) and extract it into a folder named FitAI.
2. Open the extracted folder in Android Studio.
3. Allow Gradle sync, then run the app on an Android device (Android 7.0 / API 24 or newer).

The archive contains the complete project source, Gradle wrapper and build configuration, Android tests, trained model assets, Python training script, public training dataset, evaluation results, and detailed project documentation. Build caches, machine-specific settings, and signing keys are excluded.

See the README.md and DELIVERY-NOTES.md inside the archive for setup, features, model limitations, and prior validation results.

The source is packaged as an archive to preserve its Android project folder structure during browser upload.
